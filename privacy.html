Privacy Policy

Last updated: 2026-11-19

make-secondbrain ("the app") is a personal tool used only by its owner. This policy explains how it handles Google user data.

Data accessed

With the owner's consent through Google OAuth, the app may access the owner's Google Drive, Docs, Sheets, Calendar, Tasks, Gmail and other Google Workspace data, only within the scopes the owner approves.

How data is used

Data is used only to carry out the owner's own requests (for example reading or editing the owner's files) on the owner's own computer. It is not used for advertising, not sold, and not shared with any third party.

Storage

OAuth tokens are stored only on the owner's computer. The app runs no server and keeps no copy of Google data elsewhere.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions can be sent through the GitHub profile github.com/realbroj.
